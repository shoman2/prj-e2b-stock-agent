# E2B Stock Quant Agent (글로벌 5대 주가지수 AI 분석 플랫폼)

E2B 클라우드 파이썬 샌드박스(`@e2b/code-interpreter`)를 활용하여 글로벌 5대 주요 주가지수를 분석하고 시각화하는 AI 퀀트 에이전트 웹 애플리케이션입니다.

## 📌 지원 지수
- **S&P 500 (`^GSPC`)**: 미국 대형주 500개 대표 시장 벤치마크
- **NASDAQ 종합 (`^IXIC`)**: 빅테크 및 혁신 성장주 중심 지수
- **Russell 2000 (`^RUT`)**: 미국 중소형주 지수 (금리 및 내수 민감)
- **KOSPI (`^KS11`)**: 대한민국 유가증권시장 대표 종합주가지수
- **KOSDAQ (`^KQ11`)**: 대한민국 기술·바이오 중심 중소형 성장주 지수

## 🚀 주요 기능
- **실시간 지수 모니터링**: 5대 지수의 현재가, 등락률, 7일 스파크라인, 52주 고저가 밴드
- **정규화 수익률 비교 차트**: 기준점(=0%) 대비 지수 간 상대 수익률 비교 (1M, 3M, 6M)
- **E2B AI 퀀트 에이전트**:
  - 한·미 주요 지수 상관관계 매트릭스 (피어슨 상관계수 히트맵)
  - 연간 변동성 및 최대낙폭(MDD) 리스크 비교 (듀얼 막대 차트)
  - 미국 대형주 vs 소형주 상대강도 추이 (RUT/GSPC 비율)
  - 5대 지수 RSI(14) 및 이평선 기술적 스캐너
  - 자연어 프롬프트 기반 자동 파이썬 코드 생성 및 E2B 샌드박스 실행

## 🛠️ 기술 스택
- **프론트엔드/백엔드**: Next.js 14 (App Router, TypeScript)
- **샌드박스 런타임**: `@e2b/code-interpreter` (Python 3.11 MicroVM)
- **데이터 분석 툴**: yfinance, pandas, numpy, matplotlib, seaborn
- **스타일링**: Vanilla CSS / 모던 핀테크 다크 테마

## ⚙️ 실행 방법

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드 및 실행
npm run build
npm start
```
